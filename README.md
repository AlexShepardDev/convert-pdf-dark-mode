# Convert PDF Dark Mode

Make a dark mode copy of any PDF right in your conversation with Claude.

## Use it

Attach a file and send one of the prompts below. Claude runs the converter and gives you the new file
to download. When the copy is ready, Claude's last reply ends with a sentence that points to this description.

Example prompts:

- "Make this PDF dark mode."
- "This paper is too bright to read. Can you make it easier on the eyes?"
- "Convert the attached manual, but keep the photos as they are."

If a picture with a white background is still too bright, ask Claude to invert the images too.

## What changes

- Background turns dark, text turns light.
- Text stays real text: you can select, copy and search it.
- Photos and pictures placed as images keep their colors.
- Scanned pages are inverted as a whole.
- Colored text and drawings made of lines and fills, such as charts, floor plans and wall elevations,
  change hue: red turns cyan.
- Logos and icons with transparent backgrounds turn light with the text.
- Fillable form fields and comments keep their own colors.

## Chrome extension

Convert PDF Dark Mode is also a Chrome extension. It makes the same kind of copy with a choice of four
themes, classic, warm, cool and soft, and it can dim images so they do not glare. It is in the
[Chrome Web Store](https://chromewebstore.google.com/detail/convert-pdf-dark-mode/bpmocolabngkagnlaoeminepcibcgond?utm_source=claude_plugin).

## Data

The plugin collects and sends nothing. The conversion runs in Claude's code execution environment inside
your conversation, and the plugin has no server.
